# Plain Frontend Scaffold

Use this scaffold for small or page-local features.

## Included Layers

- `frontend/pages/sample-feature/`
    - `index.html`: page structure
    - `styles.css`: page styles
    - `app.js`: page orchestration
- `frontend/shared/auth/oauth.js`
    - OAuth2 login and token helpers
- `frontend/shared/api/http.js`
    - shared HTTP wrapper
- `frontend/shared/api/document.js`
    - example CrownCAD document API wrapper
